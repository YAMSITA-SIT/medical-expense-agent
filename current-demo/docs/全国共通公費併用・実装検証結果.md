# 全国共通の公費併用拡張：実装結果と未完了事項

2026年9月21日／計算版 national-2.1。今回の計画全体は未完了です。月額の公費併用等を拡張しましたが、新年間上限への最終接続は根拠確認が残ります。

## 実装・検証した処理

| 処理 | 計算できる条件 |
|---|---|
| 精神通院・小児慢性・難病・医療扶助の併用 | 認定証、診療対象、指定機関、期間、保険給付配分が確認済み。法別21→52→54→12の順に、既給付と残額を調整 |
| 同じ明細の一部だけ公費対象 | 確認済み診療内訳を元明細と照合。対象部分だけに公費を適用し、非対象部分を保持 |
| 難病・小児慢性の家族配分 | 認定上の世帯全員と配分前上限が確認済み。受診のない認定受給者も確認済み名簿から計算。10円未満切捨て |
| 小児慢性の上限 | 認定所得区分、重症、人工呼吸器を使用。18～19歳は18歳前からの継続認定を確認。食事療養費は含めない |
| 公費の月途中開始・認定証変更 | 診療日ごとに有効な認定証を照合。上限が変わる月は行政の認定済み月額上限を使用。日割り・上限再付与は推測しない |
| 75歳到達・保険分割・特定疾病との公費併用 | 既存の専用算定が対応する資格・疾病条件と、確認済みの明細別給付配分を使用 |
| 無保険の他公費と医療扶助 | 公費対象費用・受給者証・医療券・他法給付が確認済み。保険給付を架空に付加しない |
| 生活保護開始前後の資格切替 | 国保または後期高齢者から医療扶助への2期間切替。保護決定、開始日、旧資格最終日、期間別明細・所得を照合 |
| 医療扶助の本人立替精算 | 福祉事務所等が認定した本人向け金銭給付額・決定番号・理由・証拠がある場合。未認定は個別認定待ち |

複数明細にまたがる公費の配分は確認済み配分を検算します。配分額を領収書の並び順だけで生成しません。制度ごとの認定・診断・支給決定そのものをAIが代行する機能ではありません。

## 計算台帳と出力

元明細と診療内訳、本人、診療日、対象費用、通常の保険給付、高額療養費、公費ごとの給付、残る本人負担を記録します。通常計算で明細別配分が未確定なら、世帯総額と明細別配分の状態を分け、配分欄に架空の金額を入れません。

本人への追加還付、医療機関への精算、保険者間精算、現物給付を別項目で返します。未解決理由は「実装未完了」「根拠未確認」「案件情報不足・不一致」「個別認定待ち」「今回対象外」を区別します。

既存APIを維持し、結果に payments、calculation_ledger、annual_preparation、findings.reason_category を追加しました。確認済み公費調整と資格切替は既存の reviewed-fact 接続口から、確認者・証拠・変更履歴付きで更新できます。

## 新年間上限の未完了部分

公費を含む12か月の月額処理を再実行し、保険給付、公費、本人負担を月別に照合する接続を追加しました。例では本人負担119,880円・公費600,120円まで照合できますが、これをそのまま年間給付の算定基礎と決定してはいません。

未確認なのは、新年間上限についての次の具体的規程です。

1. 年間中に所得区分・保険者・世帯が変わる場合の基準区分と対象範囲。
2. 外来年間給付と新年間給付の個人・家族・保険者への配分。
3. 年間保険給付の発生後、公費負担額を再調整する順序、返還・精算先。

2026年改正の公式2資料、厚労省制度ページ、国保施行令、旧外来年間の通知・Q&A、協会けんぽの改正案内等を確認しましたが、上記を新制度の実行規程として確定するには至っていません。「公開されていない」と断言しているわけではなく、こちらの根拠確認が未完了です。既存の年齢混在・21,000円未満の受診単位等の年間算定制限も残ります。停止処理や台帳準備を、年間計算の完成として数えていません。

また、認定証変更時の月額上限の自動選択、既存専用算定の対象外条件、複雑な複数回の保護開始・廃止、食事療養等の別費目は今回の確認済み処理を超えます。自治体独自助成・保険者独自給付・非公開規程は合意どおり次段階です。
