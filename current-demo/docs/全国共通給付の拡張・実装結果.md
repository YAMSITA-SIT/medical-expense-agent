# 全国共通給付の拡張・実装結果

更新：2026年9月21日。画面：http://127.0.0.1:4176/

今回、計算経路・根拠保存・職員画面を拡張しました。計画全体の無条件対応が完了した状態ではありません。特に新しい年間上限の所得・保険変更、月額給付の自動配賦、一部複合公費には未実装・確認待ちが残ります。

## 操作

案件一覧から `NATIONAL-` で始まる案件を選び、「処理開始」を押してください。明細は入力済みです。資格・所得・認定情報をDBから読み、療養費本体・月額高額療養費・年間給付・公費の追加額を区別して表示し、結果を保存します。

## 計算可能な条件と残る制限

| 対象 | 今回計算できる条件 | 未実装・確認待ち |
|---|---|---|
| 月額高額療養費 | 国保・後期に加え、被用者保険・共済の認定所得区分、被保険者・被扶養者の紐付けを確認した法定給付 | 独自付加給付。特定疾病と被用者保険・共済等の未対応の組合せ。年齢・資格の特殊な移行 |
| 年間 | 従来の単独加入者計算に加え、確認済み個人別月額配分台帳のある継続世帯。旧外来年間上限は所得・保険変更台帳を通算 | 月額給付配分の自動作成。新年間制度の所得・保険変更の区分選択・保険者配分。年齢混在世帯、21,000円未満の明細を含む複雑な集計。旧制度の保険者別支払配分は別途確認 |
| 海外療養費 | 被用者保険の確認済み国内相当額、円換算実費、決定日の換算証拠、自己負担相当額、給付対象認定 | 外貨明細からの自動換算・国内相当額査定。他保険制度の換算・算定規程。治療目的渡航等の認定判断 |
| 装具 | 医師の必要性認定、保険者認定費用、対象購入費用、自己負担相当額、算定月が確認済み | 装具価格表の自動査定、採寸・採型等からの算定月の自動決定 |
| 第三者行為 | 非係争・保険適用確認済み、給付に対応する賠償控除額が確認済み | 損害項目からの控除額の自動認定、責任割合の判定、求償処理。別制度との複合調整 |
| 労災 | 認定済みの対象費用、本人支払、健康保険への返還、既払と精算経路を確認 | 労災認定そのもの、未認定・係争中、他例外との複合算定 |
| 指定難病・精神通院 | 単独受給者・全明細が対象診療、受給者証・指定医療機関・認定所得区分・上限を確認。公費現物給付は明細別配分も照合 | 非対象診療の混在、世帯内複数受給者、複数公費、生活保護、自立支援の上限なし区分、療養費・年間との複合調整 |

申請期限は、給付ごとの**確認済み起算日・期限・根拠**を保持して照合します。全制度の時効起算・中断等を自動認定する実装ではありません。精神通院の一定所得以上の経過特例は2027年3月までとし、4月以降に流用しません。2027年8月以降の診療に今回の計算表を流用しません。

新年間制度の変更時処理は、改正説明資料だけから区分選択・配分を推測せず、厚労省・保険者の事務取扱通知の確認を残しています。装具の価格査定・時効・算定月、第三者の給付対応賠償認定、公費の複合配分は、それぞれ保険者給付担当／公費制度担当が確認先です。全自治体の独自制度や全組合独自規程は今回の対象外です。

## 情報の確認状態・保存

- DBに存在するだけでは確認済みにしません。通常データは項目別の確認状態と証拠が必要です。
- 既存119案件には「架空テストデータとして確認済み」という専用属性のみを追加しました。実データの認定とは分けています。明細・職員編集・認定事実は変更していません。
- 新しい10案件を別IDで追加し、計129案件です。期待額はテストコード内に分離し、Agentや案件DBに渡していません。
- 今回12資料の原本をローカルとSupabaseの非公開Storageに保存し、条項・ページ・対象期間・対象制度・検証状態を登録しました。新規21検索区画、従来分を含め75区画です。PDF以外の公式HTMLも原本として保存しています。
- 算定規程は検証済み版だけを選択します。確認中の資料は検索参考候補として利用できますが、検索結果だけで計算を有効化しません。
- 月額給付の家族配分は確認済み証拠と月額の再計算額を照合します。食い違う場合、年間額・合計額は未確定です。
- 修正明細と認定情報が矛盾した場合、認定情報を上書きしません。根拠検索までで停止し、生成AI・照会送信・正式決定・送金は実行しません。

## 検証

既存218件を含む257件のテストが成功しました。専用経路を追加した5分類の認定情報欠落は、従来の「専用ルール未実装」から「情報不足」へ期待結果を更新しています（海外の国保未対応は専門判断のまま）。

検証には所得認定不足、異なる被保険者への扶養紐付け、古い認定の流用、換算日不一致、期限外、認定期間外、2027年3月／4月境界、公費現物・既払の控除、賠償、労災精算、年間台帳の不整合、再実行を含みます。

実接続でも新規9案件の算定結果保存を確認しました。海外案件はブラウザで案件選択・実行・保存・支払額変更・不一致停止・元の額への復元と再計算を確認しました。既存の編集済みP01-1の点数150、支払額5,242円、保険外1,000円を保持しています。並行実行、古い入力版の拒否、不正入力時の保持、承認されていないAI経路の停止も確認しました。
