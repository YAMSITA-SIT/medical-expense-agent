# 年間配分・精神通院・再処理の追加結果

2026年9月21日更新。職員画面：http://127.0.0.1:4176/

## 今回追加したもの

- **年間配分**：2026年7月までの被用者保険、70歳以上の通常世帯、個人・入院外来別の月額集約明細について、世帯給付を個人、さらに入院・外来へ自動配分します。端数は通知の方式に従います。旧外来年間上限の保険者別配分も、対象条件を満たす台帳で計算します。
- **精神通院の典型ケース**：指定薬局との合算、中間所得の個別月額上限なし区分、対象外の他科診療との混在を追加しました。混在時に高額療養費が発生する場合は、対象診療へ配分した保険給付の確認済み情報が必要です。
- **確認と再処理**：未解決事項ごとに確認先・必要資料・質問の定型案を表示します。職員による確認済み回答の登録口を追加し、変更前後・確認者・証拠・入力版を保存します。所得区分については画面から回答を登録して再処理できます。受給者証等の回答登録は接続口までで、専用入力画面は未追加です。

確認案は定型処理です。生成AIの推論・自動送信・外部照会は実行していません。OrcaRouterの無承認呼出しはありません。

## なお残る範囲

- **2026年8月以降の新年間制度における所得・保険変更**：今回の旧制度通知を流用せず、適用できる通知の確認待ちです。
- 自動配分の対象外：国保・後期・共済、新制度、年齢混在、特殊給付、同一人物・入院外来区分内の複数明細。端数が生じ、最小配分額が同額になる場合も保険者の扱いを確認します。
- 複数公費、複数受給者の公費上限配分、複雑な高額療養費との混在、生活保護等は引き続き未対応です。
- 文書を根拠に生成AIが個別の次の行動を推論する段階、照会送信、外部情報取得、回答の真偽・認定の自動確認は未実装です。

全国共通計算の全条件を完了したという意味ではありません。対応済み条件以外では未確定として確認案を表示します。
