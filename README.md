# 医療費サポートナビ 

*LLM（OCR/データ構造化）× 決定論的プログラム（厳密計算）による高額療養費・医療費助成の自動判定AIエージェント

医療費サポートナビは、複雑な医療費支援制度（高額療養費制度・自治体ごとの医療費助成など）の対象可否および給付金額を、**1円の誤差もなく確実に算出・案内するAIエージェント**です。

汎用LLM（ChatGPT等）の「非決定性（確率的出力・ハルシネーション）」を排除し、AIによる書類解析とプログラムによる決定論的アルゴリズムを明確に分離した堅牢なシステムアーキテクチャを採用しています。

---

##  解決する課題

病気や怪我で医療費が高額になった際、日本の公的保険制度では各種助成を受けることができます。しかし、以下のような構造的課題が存在します。

1. **複雑すぎる適用条件**: 年齢・所得区分・加入保険・診療月・世帯合算など、考慮すべきパラメータが膨大。
2. **申請主義の壁**: 制度があっても自動では給付されず、本人が認知して申請しなければ受け取れない。
3. **申請手続きの難易度**: 専門用語が多く、必要書類や申請先の特定で挫折してしまう。

本プロダクトは、この複雑なプロセスを**「領収書を撮って簡単な質問に答えるだけ」**の状態へと変革します。

---

## なぜ汎用LLM（ChatGPT）単体では駄目なのか？

お金や公的給付を扱うシステムにおいて、一般的なチャットAI（ChatGPT等）に計算やロジック判定を丸投げすることは非常に危険です。

| 比較項目 | 汎用LLM（ChatGPT単体） | 本プロダクト（医療費サポートナビ） |
| :--- | :--- | :--- |
| **アーキテクチャ** | 確率に基づくテキスト生成（非決定的） | **LLM（抽出） + 確定プログラム（計算）** |
| **計算の再現性・信頼性** | 質問の聞き方で回答が変わる／ハルシネーションのリスク | **同じ入力なら常に100%同じ計算結果を保証** |
| **ユーザー負担** | 前提条件や制度ルールをユーザー自身が把握・入力 | **OCRと対話型フォームで最短入力** |
| **制度ルールの管理** | 過去の学習データ依存（古い法改正に対応できないリスク） | **プログラム・ルールエンジン側で法改正に対応** |
