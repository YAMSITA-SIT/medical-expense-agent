# 国保給付エージェント PoC

構造化された申請から、模擬台帳照会、決定論的ルール計算、職員決裁、通知書、模擬支払をつなぐプロトタイプです。独立した生成AIモデルは接続していません。WebMCP対応ブラウザではAIが公開ツールから申請を読み、審査を実行できます。金額の決定はLLMに任せません。

## 起動・検証

Node.js 22以降。外部パッケージ不要。

```
npm start
npm test
```

起動後 http://127.0.0.1:4173 を開きます。初期ケースで「審査→決裁→模擬振込」の順に操作します。上部で7つの検証ケースを切り替えられます。入力変更時は直前の審査と決裁が失効します。

## 出力

- 決裁後：通知書TXT、印刷/PDF
- 審査後：審査・実行記録JSON
- 保留時：職員確認依頼TXT
- 模擬振込後：銀行未接続の模擬振込CSV

## 対象

国保・18〜69歳・3割負担・単独被保険者・単一医療機関／単一レセプト・支払済みの通常償還払い。2026年1〜7月と2026年8月〜2027年7月の所得5区分と多数回の月額計算。年間上限の可能性は職員確認へ回します。世帯合算、70歳以上、現物給付、公費、保険者変更等は対象外です。国保の支給主体は保険者であり、厚生労働省が全国の申請に直接送金する構成ではありません。

## 構成

- `dist/engine.js`：照合、診療月別ルール、状態遷移、支払重複チェック、模擬照会台帳
- `dist/app.js`：画面、出力、WebMCP
- `dist/index.html`：業務画面、対象範囲、資料リンク
- `tests/engine.test.mjs`：16項目の計算・業務制御テスト

WebMCP: `read_benefit_case`、`stage_benefit_scenario`、`run_benefit_review`。決裁・送金ツールは公開せず、画面から職員が操作します。

## 検証実績

16項目の自動テストが成功。ブラウザで標準審査→模擬決裁→模擬振込→再審査時の重複停止、資料不足時の保留を確認。WebMCPの3ツール登録、正常入力、不正入力拒否、状態読戻しを確認。

標準例：2026年8月・区分ウ・総医療費1,000,000円、支払額300,000円。限度額92,940円、支給案207,060円。2026年7月の同条件は212,570円。多数回例は255,600円。

## 本番化前に必要なこと

実個人情報を入れず、架空データだけで検証してください。資格・税情報・レセプト・銀行は模擬データです。状態はメモリ内のみで、ページ再読込・初期化で消えます。多端末の重複排除や改ざん防止を備えた監査ログではありません。

生成AIによる申請文／OCRの構造化、本人・職員認証、サーバー側検証、保存、権限分離、実データ接続、トランザクション／冪等キーの永続化、振込結果照合が必要です。通知書は正式様式ではなく、不服申立て等の必須記載を網羅しません。2026年8月の数値は厚労省の公表説明資料を参照し、法令の施行履歴との完全照合、標準仕様書の帳票・連携完全準拠は未完了です。

参照URLは画面「制度・対象範囲」および `SOURCES` に保存。参照日2026年9月20日。
